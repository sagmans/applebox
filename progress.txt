## Codebase Patterns
- Test files go in `Tests/AppleBoxTests/`
- Mock implementations go in `Tests/AppleBoxTests/Mocks/`
- Snapshot reference images go in `Tests/AppleBoxTests/__Snapshots__/<TestClass>/`
- Use `@testable import AppleBox` to access internal module members in tests
- Run `swift build` before `swift test` to catch compilation errors faster
- Dependency protocols go in `Sources/AppleBox/Protocols/`
- Production implementations of protocols go in `Sources/AppleBox/System/`
- When refactoring classes for DI, change `private let x = X()` to `private let x: XProtocol` and inject via init
- When creating user home directory paths in tests, use `isDirectory: true` in appendingPathComponent to match ApplicationIndexer behavior
- For snapshot tests, use `assertSnapshot(of: view, as: .image)` and call `layoutSubtreeIfNeeded()` before capturing
