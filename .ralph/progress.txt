- UI window layout/styling is in `Sources/AppleBox/WindowManager.swift` (borderless `AppleBoxWindow` + AppKit views).
- Respect Reduce Motion via `NSWorkspace.shared.accessibilityDisplayShouldReduceMotion` before running AppKit animations.
- Snapshot tests: run `RECORD_SNAPSHOTS=1 swift test --filter SnapshotTests` to update PNGs, then re-run without `RECORD_SNAPSHOTS` to assert.
- Fuzzy matching returns `FuzzyMatchResult` with `score` and `matchedIndices` via `FuzzyMatcher.matchWithIndices()`.
- Use `attributedStringValue` with `NSColor.controlAccentColor` for match highlighting in table cells.
- Search is debounced at 50ms via `DispatchWorkItem` to avoid per-keystroke overhead; `simulateSearch()` bypasses debounce for tests.
- Use `ClipboardManager.searchHistoryWithMatches()` to get score+indices in one pass (avoids duplicate fuzzy matching).
